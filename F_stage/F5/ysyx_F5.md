# **10以内奇数求和**

| 指令编号 | 汇编指令         |
| -------- | ---------------- |
| 0        | li r0 $11        |
| 1        | li r1 $0         |
| 2        | li r2 $1         |
| 3        | li r3 $2 //改为2 |
| 4        | add r1 r1 r2     |
| 5        | add r2 r2 r3     |
| 6        | bner0 4 r2       |
| 7        | benr0 7 r1       |

机器码：

8b 90 a1 b2 16 2b d2 dd

10001011 10010000 10100001 10110010 00010110 00101011 11010010 11011101
![image-20260413235912774](pic/image-20260413235912774.png)

结果为25
